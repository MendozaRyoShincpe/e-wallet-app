# CICO E-Wallet App

A desktop-based e-wallet application developed using Python and Tkinter for an Object-Oriented Programming (OOP) project.

## Features
- Login Interface
- Main Dashboard
- Send Money
- Pay Bills
- Cash In
- Cash Out

## Technologies Used
- Python
- Tkinter
- Pillow (PIL)

## How to Run
1. Install Python 3.
2. Install Pillow: `pip install Pillow`
3. Run the application: `python main.py`

## Purpose
This project simulates basic e-wallet transactions for educational purposes.
